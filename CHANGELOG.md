# Changelog

All notable changes are documented here. This project follows Semantic Versioning.

## 0.1.0 - 2026-08-18

### Added

- Strict versioned YAML/JSON behavioral contract models.
- Required, forbidden, argument, order, budget, JSON Schema, and approval checks.
- Framework-neutral adapter protocol and deterministic agent/tool doubles.
- CLI with stable exit codes and machine-readable reports.
- pytest fixture and assertion integration.
- Python 3.11 through 3.14 package metadata and CI verification.
