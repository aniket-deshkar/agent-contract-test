# Security Policy

## Supported Versions

Security updates are applied to the latest minor release. Consumers should reproduce reports with the newest release before filing an issue.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for suspected unsafe deserialization, adapter loading, schema-validation denial of service, or report-data disclosure. Include affected versions, impact, and a minimal reproduction without real prompts, credentials, tool arguments, or customer responses.

Maintainers will acknowledge a complete report within five business days and coordinate remediation and disclosure.
